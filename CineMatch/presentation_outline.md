# CineMatch — CAT 2 Presentation (Suggested 10 slides)

1. **Title** — CineMatch: Machine Learning Based Movie Recommendation System
2. **Problem Statement** — Large catalogues make relevant movie discovery difficult.
3. **Objectives** — Build content-based recommendations using movie metadata.
4. **Proposed System** — Explain content-based filtering and user workflow.
5. **Architecture** — CSV → preprocessing → TF-IDF → Cosine/KNN → top-five results.
6. **Algorithms** — TF-IDF, cosine similarity and KNN with cosine distance.
7. **Implementation** — Python, Pandas, Scikit-learn, Streamlit; show project structure.
8. **Live Demo** — Select a movie, choose method, show recommendations.
9. **Performance & Limitations** — Catalogue coverage, latency, qualitative relevance; no fabricated accuracy.
10. **Conclusion & Future Work** — Hybrid recommendations, user feedback, larger dataset.

Design: beige background, muted lavender accents, dark charcoal text, simple rectangular cards, consistent typography.
